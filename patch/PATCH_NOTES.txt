SIGNATURE LLAMA — WHOLE PATCH v1
Signature Llama: The Fully Cyber Utilizable AI
Independent model by Justin Addam Higgins. Not affiliated with Meta.

WHAT THIS IS
------------
Everything needed to run, study, and build on Signature Llama v1 —
her own tiny transformer, written and trained from scratch. One zip,
no build step, no keys, no fees.

WHAT IS INSIDE
--------------
engine/sigllama.js ......... The pure-JavaScript inference engine (SigLlama global).
weights/ ................... sigllama-v1.bin (int8 weights) when published,
                             or WEIGHTS_PENDING.txt explaining the model is
                             still training and where to check.
vocab.json ................. The character vocabulary.
src/ ....................... All the Python sources: tokenizer, transformer
                             model, trainer, exporter/quantizer, corpus
                             builder, parity checker.
data/llm-dictionary.json ... 312 original one-sentence LLM/AI definitions.
data/explainer-kb.json ..... The on-site guide knowledge base.
llama-api.js ............... SignatureLlama.ask(question) -> Promise<string>.
llama-manifest.json ........ Machine-readable manifest (start here, AIs).
llms.txt ................... Plain-words summary for AI readers.
embed-snippet.html ......... Copy-paste 3-line web embed.
PATCH_NOTES.txt ............ This file.

HOW TO USE IT
-------------
1. Unzip anywhere.
2. Open embed-snippet.html in a browser, or copy its <script> block
   into your own page.
3. Or ask it questions from any page:
     <script src="llama-api.js"></script>
     <script>SignatureLlama.ask("What is a token?").then(console.log);</script>
