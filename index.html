★ USE IT IN YOUR CREATIONS

Put Signature Llama in your own pages, games, and apps. No setup, no keys — click, copy, or download.

The embed code is 3 lines: load the engine, load the model, generate text. Paste it into any web page. It must be a type="module" script — only a module allows the top-level await; that requirement is written into the snippet itself.

<script src="https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/sigllama.js"></script>
<script type="module">
// type="module" is REQUIRED: only a module script allows the top-level await below.
// First load needs internet (engine + ~3 MB weights). Failures surface by name —
// see llama-manifest.json "failure_states" (ENGINE_LOAD_FAILED, MODEL_NOT_FOUND, ...).
await SigLlama.load('https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/');
const reply = await SigLlama.generate('Hello, Llama.', { maxTokens: 60 });
document.body.insertAdjacentHTML('beforeend', '<p>' + reply + '</p>');
</script>

● RUNTIME COMPATIBILITY

    
Where Signature Llama runs — stated only from what this site has actually established. No lab claims beyond these.

    
BrowserAny modern browser with JavaScript. The engine is one dependency-free file; unsupported browsers get a named failure (BROWSER_UNSUPPORTED) instead of silence.

    
DesktopYes — anything that runs a modern browser, any OS.

    
MobileYes — the same page; read-aloud is chunked so long replies are not cut off on phones.

    
OnlineRequired for first load: the engine (~12 KB) plus the weights (~3 MB) download from signature-backend.

    
OfflineAfter the first load, your browser's HTTP cache can serve the files offline. Offline use is not guaranteed and has not been lab-tested — it depends on your browser's cache.

    
Model limitsThe model itself does local text generation only — no network, no files, no device access. Tool libraries are optional plug-ins; only the ones you load run, and only as ordinary page JavaScript.

    // temperature: any real number, default 0.8. Typical 0–1.5.
//   temperature <= 0 → greedy argmax: NO randomness, same prompt → same output.
// topK: integer ≥ 1, default 40. Only applies when 1 ≤ topK < 84 (vocab size).
// maxTokens: integer ≥ 1, default 120. stopAtEos: default true.
// CONTEXT: 128 tokens. Your prompt is LEFT-TRUNCATED to (128 − maxTokens − 2)
// tokens — a bigger maxTokens leaves less room for the prompt.
// Deterministic (site-level LlamaRuntime): { deterministic: true } forces
// temperature 0; { seed: 1234 } seeds the sampler. Both give byte-identical

● DATA & METHODOLOGY

    
How Signature Llama v1 was built, what the files are, how to check them, and what is local versus cloud. Nothing here is a metaphor: the numbers below are the actual model facts.

    
Model card summary

    
ArchitectureDecoder-only transformer, hand-written from scratch — no borrowed code, no pretrained weights.

    
Scale2,983,488 parameters (~3M): 5 layers, 8 attention heads, hidden size 192, context 128 tokens, 84-token character-level tokenizer.

    
Training12,890 steps on a 135,340-line / 23.2 MB creator-authored corpus (IWB Dictionary definitions + Signature spec text, seed 614); finished 2026-09-30; weights published 2026-09-30 22:39 EDT.

    
Honestyv1 is small, lively and a little quirky — like a bright intern. It can invent facts — verify anything important.

    
SGLL weights format

    
Weights ship as a SGLL v1 binary file (sigllama-v1.bin, 3,042,035 bytes): the full 2,983,488 parameters in int8 with per-row scales — each row of the weight matrices is stored as 8-bit integers plus one scale value, so the whole model downloads in seconds and runs in a few megabytes of memory. The matching engine is sigllama.js (11,683 bytes, pure JavaScript, zero dependencies) with vocab.json (84 characters).

    
Hash verification

    
The official weights hash is b2dfc0d05add95786797e596559f3e86de9b3a9c9dbce6818814ad05d6317b58 (SHA-256) and the official engine hash is 6188cb269e07a134e865de4f7b68ee8c5dcfd1bde8771ad2c7b574a2edb4355a. To verify a copy: download the file, compute its SHA-256 (for example sha256sum sigllama-v1.bin on a computer, or any SHA-256 tool), and compare to the hash above — they must match exactly. The page's Downloads panel checks the hashes automatically at runtime and names the failure if a file does not match (MODEL_CORRUPT).
