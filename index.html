Put Signature Llama in your own pages, games, and apps. No setup, no keys — click, copy, or download.

The embed code is 3 lines: load the engine, load the model, generate text. Paste it into any web page. It must be a type="module" script — only a module allows the top-level await; that requirement is written into the snippet itself.

<script src="https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/sigllama.js"></script>
<script type="module">
// type="module" is REQUIRED: only a module script allows the top-level await below.
// First load needs internet (engine + ~4 MB weights). Failures surface by name —

document.body.insertAdjacentHTML('beforeend', '<p>' + reply + '</p>');
</script>

Where Signature Llama runs — stated only from what this site has actually established. No lab claims beyond these.

    
BrowserAny modern browser with JavaScript. The engine is one dependency-free file; unsupported browsers get a named failure (BROWSER_UNSUPPORTED) instead of silence.

    
DesktopYes — anything that runs a modern browser, any OS.

    
MobileYes — the same page; read-aloud is chunked so long replies are not cut off on phones.

    
OnlineRequired for first load: the engine (~13 KB) plus the weights (~4 MB) download from signature-backend.

    
OfflineAfter the first load, your browser's HTTP cache can serve the files offline. Offline use is not guaranteed and has not been lab-tested — it depends on your browser's cache.

● DATA & METHODOLOGY

    
How Signature Llama v2 was built, what the files are, how to check them, and what is local versus cloud. Nothing here is a metaphor: the numbers below are the actual model facts.

    
Model card summary

    
ArchitectureDecoder-only transformer, hand-written from scratch — no borrowed code, no pretrained weights.

    
Scale4,056,768 parameters (~4M): 5 layers, 8 attention heads, hidden size 192, context 96 words, 2,879-token word-level tokenizer.

    
Training7,200 steps on 28,737 persona-dialogue examples (~1.88M tokens) distilled from the phone book's 270 AI profiles; trained to validation loss 0.064 (~3.2 epochs); weights published 2026-10-03.

    
Honestyv2 is small and lively. Coherent replies pass the on-page coherence gates about a third of the time on generic chat — it can mix abilities across the 270 AIs. The human JAHtalk fallback guarantees every answer stays coherent. It can invent facts — verify anything important.

    
SGLL weights format

    
Weights ship as a SGLL v1 binary file (sigllama-v2.bin, 4,137,675 bytes): the full 4,056,768 parameters in int8 with per-row scales — each row of the weight matrices is stored as 8-bit integers plus one scale value, so the whole model downloads in seconds and runs in a few megabytes of memory. The matching engine is sigllama.js (15,535 bytes, pure JavaScript, zero dependencies) with vocab2.json (2,879 word tokens).

    
Hash verification

    
The official weights hash (official within the Signature/JAH system) is e351a9e1133a1774782d9f6f0e77f6ab756ca769af59fbbe763f6321e32d7049 (SHA-256) and the official engine hash (official within the Signature/JAH system) is a8bc903a244c7f2ea8575100433548bfe238a468fb0012a956be6e986a47e50b. To verify a copy: download the file, compute its SHA-256 (for example sha256sum sigllama-v2.bin on a computer, or any SHA-256 tool), and compare to the hash above — they must match exactly. The page's Downloads panel checks the hashes automatically at runtime and names the failure if a file does not match (MODEL_CORRUPT).

    
Local vs Industry Standard

    
✦ Signature Llama v2 (LOCAL)The trained 4,056,768-parameter word-level chat model, running on your device in the browser. No keys, no fees, no network calls — local text generation only, 96-word context.

    
⬢ Llama · Industry Standard (CLOUD)The full-scale Llama the industry runs (default Llama 3.3 70B; Llama 4 Maverick / Llama 4 Scout selectable, 128k context), served live from the cloud by Groq. Needs a free API key (bring-your-own, stored only in your browser). Llama weights are by Meta; this site is independent, not affiliated with Meta.

    
Never confusedThe chat box has a model picker; every reply is labeled with which engine answered — ✦ Trained Llama v2 · SIGLLAMA-V2 · LOCAL · ON-DEVICE, or ⬢ Industry Standard · CLOUD · REMOTE (served by Groq). The legend: ✦ = the local Signature model on your device · ⬢ = the external cloud model. A knowledge-base answer is always labeled Guide — never "Llama".
