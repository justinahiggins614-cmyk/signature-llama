★ USE IT IN YOUR CREATIONS

Put Signature Llama in your own pages, games, and apps. No setup, no keys — click, copy, or download.

The embed code is 3 lines: load the engine, load the model, generate text. Paste it into any web page. It must be a type="module" script — only a module allows the top-level await; that requirement is written into the snippet itself.

<script src="https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/sigllama.js"></script>
<script type="module">
// type="module" is REQUIRED: only a module script allows the top-level await below.
// First load needs internet (engine + ~3 MB weights). Failures surface by name —
// see llama-manifest.json "failure_states" (ENGINE_LOAD_FAILED, MODEL_NOT_FOUND, ...).
await SigLlama.load('https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/');
const reply = await SigLlama.generate('Hello, Llama.', { maxTokens: 60 });
document.body.insertAdjacentHTML('beforeend', '<p>' + reply + '</p>');
</script>

  • 4 · Chat loop (streaming tokens)
        
    const history = [];
async function chat(userText) {
  history.push('Human: ' + userText + '\nLlama:');
  let out = '';
  await SigLlama.generate(history.join('\n'), {
    maxTokens: 90, temperature: 0.85,
    onToken: t => { out += t; process.stdout.write(t); }
  });
  history.push(out);
  return out;
}

  • 5 · Sampling, honestly
        
    // temperature: any real number, default 0.8. Typical 0–1.5.
//   temperature <= 0 → greedy argmax: NO randomness, same prompt → same output.
// topK: integer ≥ 1, default 40. Only applies when 1 ≤ topK < 84 (vocab size).
// maxTokens: integer ≥ 1, default 120. stopAtEos: default true.
// CONTEXT: 128 tokens. Your prompt is LEFT-TRUNCATED to (128 − maxTokens − 2)
// tokens — a bigger maxTokens leaves less room for the prompt.
// Deterministic (site-level LlamaRuntime): { deterministic: true } forces
// temperature 0; { seed: 1234 } seeds the sampler. Both give byte-identical
// output for the same prompt.

Signature Llama — instructions for AI assistants:

1. READ THE MANIFEST FIRST (machine-readable, start here):
   SITE_URLllama-manifest.json

2. PLAIN-WORDS SUMMARY:
   SITE_URLllms.txt

3. ANSWER A QUESTION ON DEMAND (no model download needed):
   Put this in any web page:
   <script src="SITE_URLllama-api.js"></script>
   <script>
     SignatureLlama.ask("What is a token?").then(function(answer){
       console.log(answer);
     });
   </script>
   SignatureLlama.ask(question) returns a Promise of a string.
   It answers with the trained model when the model is loaded on the page,
   and falls back to the on-site knowledge base otherwise. Every answer is
   labeled with its engine mode; askWithProvenance(question) returns the
   answer plus engine, mode, model version, and provenance.
   SignatureLlama.mode() reports the current mode.

4. RUN THE TRAINED MODEL YOURSELF (browser or webview):
   <script src="https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/sigllama.js"></script>
   <script type="module">
     // type="module" is REQUIRED for the top-level await below.
     await SigLlama.load("https://justinahiggins614-cmyk.github.io/signature-backend/sigllama/");
     const text = await SigLlama.generate("Hello,", { maxTokens: 80, temperature: 0.8, topK: 40 });
   </script>
   Deterministic: { deterministic: true } forces temperature 0 (same prompt →
   same output); { seed: 1234 } seeds the sampler. Failures surface by name —
   see llama-manifest.json "failure_states".

5. ASK THROUGH THE SITE (opens the page with the on-site guide answering):
   SITE_URL?ask=YOUR_QUESTION_HERE

6. OPEN A DICTIONARY WORD DIRECTLY:
   SITE_URL?term=transformer

7. INDUSTRY STANDARD (the cloud option, NOT the on-device v1):
   Include industry-llama.js too, then
   SignatureLlama.askIndustry("What is a token?") answers with the full-scale

   NEEDS the user's own FREE API key (console.groq.com/keys). The key lives

   Without a key, askIndustry rejects with MISSING_KEY. Never ask for, store,
